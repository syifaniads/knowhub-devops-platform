# Repository provenance

This repository intentionally combines several historical sources into one reviewer-friendly tree.

## Provenance chain

1. `syifaniads/react-firebase-devops` — early frontend, branch/PR, Firebase CI/CD, Docker/security work.
2. `syifaniads/tes` — duplicate/late personal mirror; deprecated for portfolio use.
3. `Final-Project-DevOps/devops-platform-frontend` — final team frontend lineage. Several commits share the same SHA with the personal mirrors.
4. `Final-Project-DevOps/devops-platform-backend` — final backend source and backend GHCR pipeline.
5. `Final-Project-DevOps/infrastructure` — later infrastructure documentation/consolidation.
6. Final Project DevOps report — evidence for the assessed Swarm topology, Docker Secrets/Config, volumes, monitoring, and workflow screenshots.

## Attribution rule

A repository being under the portfolio owner's account is not used as proof that every commit was authored by the owner. Direct Syifani contribution is documented only when supported by Git authorship, personal branch/PR history, or project-level evidence. Team-level components remain attributed to the team.
